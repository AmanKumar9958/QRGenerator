# QR Generator 📱

A user-friendly web application that allows you to create QR codes instantly. With the help of the [QRserver API](https://goqr.me/api/), users can:  
- Enter any text or URL to generate a QR code.  
- View the generated QR code in real-time.  
- Download the QR code for offline use.  

## 🌐 Live Demo  
[Click here to view the QR Generator](https://amankumar9958.github.io/QRGenerator/)  

## 🛠️ Features  
- Generate QR codes for text or URLs instantly.  
- View the QR code directly on the webpage.  
- Download the QR code as an image file.  

## 🚀 How to Use  
1. Enter the desired text or URL in the input field.  
2. Click the "Generate" button to create the QR code.  
3. View the QR code displayed on the screen.  
4. Click the "Download" button to save the QR code to your device.  

## 🔧 Technologies Used  
- **HTML**: For structuring the webpage.  
- **CSS**: For styling and layout.  
- **JavaScript**: For interacting with the QRserver API and enabling functionality.  
- **QRserver API**: To generate QR codes dynamically.
